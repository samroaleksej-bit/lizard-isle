# Скрытые земли людоящеров · Остров

Модуль для Foundry VTT v13–v14: интерактивная гекс-карта острова для кампании «Скрытые земли людоящеров».

## Установка
Настройка → Дополнения → Установить модуль → поле «URL манифеста»:
```
https://github.com/samroaleksej-bit/lizard-isle/releases/latest/download/module.json
```
Включи модуль в мире → кнопка **🌴 Остров** сверху → вкладка «Импорт».

## Что умеет
- **📜 Журнал экспедиции**: задания фракций, находки, хроника, отношения с фракциями. Мастер управляет статусами прямо в книге.
- **Живая карта**: облака, блики, светлячки, подсветка гекса, аура партии. Выключить: Настройки → Модули → «Анимации острова».
- **Карточка гекса**: двойной клик по карте → местность, часы на гекс, шанс встречи, открытые находки и метки игроков. Мастер видит ещё скрытое содержимое гекса.
- **Путешествие**: мастер выбирает токен партии («Выделенный токен — это партия»). При каждом перемещении модуль считает часы, бросает встречи (к6 / к8), напоминает про переправы и усталость (больше 8 ч в пути), открывает соседние гексы. Итог шёпотом мастеру.
- **Новый день**: бросок погоды в общий чат.
- **Открыть игрокам**: места, логова, охоты, улики, данжи, квесты. Текст правится перед открытием, на карте появляется пин и страница в журнале «Дневник экспедиции».
- **Метки игроков**: Shift + двойной клик → значок и подпись на карте.
- Кнопки 📖 Дневник и 📍 Пины в верхней панели.

## Если гексы не совпали с сеткой
Настройки сцены → Сетка: тип «Шестигранники, нечётные ряды», размер 140. Если всё равно съехало, попробуй «чётные ряды».
